# ACAS LAB updates

Public downloads and the signed update feed for **ACAS LAB** (the plug-ins
**LAB FX** and **LAB Instrument**) by ACAS Tools.

Both plug-ins read `v1/latest.json` from this repository to check for updates
(once a day, or when you click **Check for updates**). The request carries no
account, project, preset or device information. The feed is signed, and the
plug-ins verify the signature and the installer's SHA-256 before offering it.
One installer per platform contains both plug-ins.
